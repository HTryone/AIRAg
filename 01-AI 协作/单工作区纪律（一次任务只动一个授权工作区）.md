# 单工作区纪律（一次任务只动一个授权工作区）

**结论**：一次任务只操作一个授权的工作区（一台机子 / 一个文件夹），需要动其他区必须先向用户申请授权，批准后才能动。

## 为什么

2026-09-28 用户定的硬纪律，原话精神："一次任务只允许操作一台机子/一个文件夹（当前授权的那个），不得乱改其他服务器/文件夹。严禁擅自跨工作区操作。这是硬纪律，无例外。"

背景：AI 排查问题时容易顺手去看、甚至去改别的服务器或文件夹——问题可能相似，但没授权就是不能动。

## 怎么做

1. 接到任务先确认当前授权范围是哪个工作区
2. 排查中发现问题指向**别的**工作区 → 停下，向用户说明情况并申请授权
3. 批准后也只动批准的那部分，不扩大
4. 主工作区只记公共内容，单服务器/单项目内容写进对应子工作区自己的 memory

## 反例

排查 A 服务器问题时发现 B 服务器有同样隐患，没打招呼就登录 B 去看或改。正确做法：报告用户，申请授权。
