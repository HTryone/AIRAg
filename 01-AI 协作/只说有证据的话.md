# 只说有证据的话

**结论**：结论里禁用"可能 / 怀疑 / 或许 / 大概率 / 应该是 / 待验证"。有证据就陈述事实并附上，没证据就直说没有证据。

## 为什么

用户原话："以后不要说可能、不要说怀疑，这种词代表你不负责，你没拿出证据。"

模糊词掩盖的是"我没验证"，用户会据此做错误决策。

## 怎么做

- 有证据：直接陈述 + 附证据（实测输出、日志、git diff、代码路径）

  ```
  定时任务没跑。证据：schtasks /query 显示上次运行结果 0x1，
  上次运行时间为空，触发器 StartBoundary 是 2026-08-29T09:00。
  ```

- 没证据：直接说"没有证据，无法确认 X，需要你提供……"

## 反例

"可能是 token 过期了" → 应该说"日志显示 HTTP 401，token 已失效"或"没拿到日志，无法确认失败原因"。
