# 浏览器扩展的加载、安装性校验与权限

**结论**：改完一个扩展，**「能装」不等于「能用」，「图标出来了」也不等于加载成功**。装法、校验、权限三件事各有各的坑。

谁需要看这条：开发/还原/审查浏览器扩展，或者要确认"改完还能不能装上"的人。

---

## 一、怎么加载一个非商店扩展

| 方式 | 现状（实测） |
|---|---|
| `chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 | ✅ 唯一稳定方式，加载目录是构建产物目录（如 `build/chrome-mv3-prod`） |
| 命令行 `--load-extension=<目录>` | ❌ 新版 Chrome 直接忽略：日志里明确写 `--disable-extensions-except is not allowed in Google Chrome, ignoring.` |
| 通过自动化调试协议（CDP）加载 | ❌ 对应的扩展域已从新版里移除 |

所以**自动化里"帮我加载扩展"这条路是断的**，只能由人在界面里点一次；AI 能做的止于「构建出可加载的目录 + 静态校验」。要确认版本，先看 `chrome://version`。

---

## 二、安装性校验：三件事逐项过

改完/还原完代码，**光看代码能读不算数**，必须证明它还原封不动是一个能被加载的扩展。

| 检查 | 查什么 | 漏了会怎样 |
|---|---|---|
| **manifest 引用全部存在** | 后台脚本、内容脚本的 js/css、web 可访问资源、弹出页、设置页，逐个确认文件存在 | 少一个文件，加载就报错，而语法错看不出来 |
| **所有 JS 语法可解析** | 用解析器（acorn 这类）把每个 `.js` 过一遍 | 拆分/改写留下的语法错，往往要用户点开某个页面才炸 |
| **与官方原包逐文件哈希比对** | SHA-256，结论分四类：字节一致 / 内容不同 / 官方有而新版缺 / 新版多出 | 说不清"到底动了什么" |

**做法**：写一个**不依赖浏览器**的校验脚本（遍历目录 → 解析 manifest 所有引用 → 确认存在 → 解析所有 JS → **有失败项退非零退出码**），接进构建脚本当闸门。

实测（2026-10-14）：一个 Parcel 打包的扩展还原成 19 个可读文件后，运行文件与官方原包**逐字节一致**，多出来的只有源码目录 —— 这才是"没改功能"的证据。

> ⚠️ 静态校验只证明**语法/结构可加载**；**运行时行为是否与原版一致**只能靠实测，别拿它冒充行为验证。

## 三、权限与网络相关字段

| 字段 | 作用 | 坑 |
|---|---|---|
| `permissions` | API 权限（如 `storage`、`scripting`） | 用了没申请的 API，运行时报错，加载时不报 |
| `host_permissions` | 允许访问的站点 | 只写主域名不够，子域要写通配（如 `https://*.example.com/*`） |
| `content_scripts.matches` | 内容脚本注入的页面 | 和 host_permissions 是两回事，两个都要对 |
| `web_accessible_resources` | 页面能直接加载的扩展内资源 | 里面列的文件路径写错，等于资源不可用 |

清单里没申请的东西**不要顺手加**；要加属于改动范围，先确认。

## 四、跨上下文通信：别用事件总线

**结论**：弹出页与内容脚本之间**不能用前端事件总线（如 mitt）**，必须走扩展自带的消息通道。

| 场景 | 用什么 |
|---|---|
| 弹出页 ↔ 内容脚本 | `chrome.tabs.sendMessage` |
| 任意上下文 ↔ 后台 | `chrome.runtime.sendMessage` |
| 后台 → 内容脚本 | `chrome.tabs.sendMessage(tabId, ...)` |

事件总线只在**同一个页面上下文**里有效，跨上下文（不同页面、不同进程）根本收不到。

## 五、避坑表

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 用命令行参数加载扩展 | 新版 Chrome 忽略，以为是加载失败 | 手动在 `chrome://extensions` 加载 |
| 只看 tsc/打包通过就交付 | 缺文件、语法错要到某个页面才炸 | 加一道「manifest 引用 + JS 解析」静态校验 |
| 拿静态校验当行为验证 | 代码能加载，但逻辑已经变了 | 行为一致性必须实测 |
| 内容脚本用 event bus 和弹出页通信 | 消息根本收不到 | 走 `chrome.*` 消息通道 |
| 只写主域名的 host 权限 | 子域名页面注入失败 | 用通配写法 |
