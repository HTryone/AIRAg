# 接口探测要有止损线

**结论**：探测未知接口时，定好"试到什么程度就放弃"，达到就停，不要无限试下去。

## 止损线

1. 换端点 × 换请求头组合，总共试不超过 6 次
2. 遇到 `403` + "请求不合法" / 签名类错误码 → 直接判定需要签名，停
3. 遇到 `401` → 是凭证问题，去查 token，不要继续换参数

## 怎么做

记录每一次尝试的**完整输入和输出**，方便最后一次性判定：

```
端点 A + 头组1 → 403 code 10085
端点 A + 头组2 → 403 code 10085
端点 B + 头组1 → 403 code 10085
...
结论：全部一致返回签名错误，判定为该接口需要额外签名，脚本无法调用。
```

判定结果写进文档 / 知识库，避免以后重复踩。

## 反例

"再试试加个 X-Client-Version 头"、"换个 body 格式"…… 试到第 10 组还是 403，浪费时间且没有任何新信息。
