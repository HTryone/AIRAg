# 多端点容错

**结论**：同一服务有多个可用域名时，依次尝试，取第一个成功的。不要写死一个。

## 为什么

单个端点可能因为网络策略、区域限制、临时故障不可用。实测 WorkBuddy 的 `copilot.tencent.com` 和 `www.workbuddy.cn` 都能调通签到接口，互为备份。

## 怎么做

```python
ENDPOINTS = [
    "https://copilot.tencent.com",
    "https://www.workbuddy.cn",
]

def call_any(path, ...):
    last_err = None
    for ep in ENDPOINTS:
        ok, data, err = post(ep, path, ...)
        if ok:
            return data, ep, None
        last_err = "%s -> %s" % (ep, err)
    return None, None, last_err
```

要点：
- 失败要记录是哪个端点、什么错，最后一并报出来
- 成功时把实际用的端点记进日志，方便以后判断哪个端点更稳
- 超时设 20 秒，太长会拖垮整个批处理
