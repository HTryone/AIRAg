# 换机或恢复服务器时参数必须按真机复核

**结论**：换机、恢复停用服务器时，调优参数（ZRAM、conntrack、journald 等）必须按当前真机的内存和磁盘重新计算，不照抄旧机器数值。

## 为什么

- 2026-09-27 S4 换机：旧参数对新机不适用，按真机 457MB 内存重算了 conntrack / ZRAM / journald 全套参数。
- 2026-09-28 S5 暂停：手册里的参数已标注为"参考值"，明确恢复启用时按真机内存复核。

参数档位跟着内存走，小内存机器差一两百 MB，ZRAM 大小、conntrack 表上限就是另一档。

## 怎么做

1. 先摸清真机现状：
   ```bash
   free -h        # 内存
   df -h          # 磁盘
   nproc          # CPU 核数
   ```
2. 按内存档位逐项复核：conntrack 上限、ZRAM 大小与算法、journald 限容、swappiness
3. 复核完把结论写回该服务器自己的手册，标注"按真机 X MB 复核于日期"

相关纪律见 [内核参数优先交发行版默认（实测异常才调）](内核参数优先交发行版默认（实测异常才调）.md)。

## 反例

换机部署时把旧服务器手册整份照抄，新机内存更小，ZRAM 配置和内存档位不匹配。
